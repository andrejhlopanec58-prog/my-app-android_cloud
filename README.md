# HTML → APK (бесплатно, в облаке)

Сборка идёт на бесплатных серверах GitHub Actions. Ничего устанавливать на компьютер не нужно.

## Как пользоваться

1. Создайте бесплатный аккаунт на github.com.
2. Создайте новый репозиторий (New repository) и загрузите в него ВСЕ файлы из этой папки
   (включая скрытую папку `.github`). Проще всего: Add file → Upload files.
3. Положите свой сайт в папку `www/` (главный файл должен называться `index.html`,
   CSS/JS/картинки — рядом).
4. Откройте вкладку **Actions** → **Build APK** → **Run workflow**
   (также сборка запускается сама при каждом коммите).
5. Через 3–6 минут откройте завершённый запуск → внизу **Artifacts** → скачайте `app-debug-apk`.
6. Распакуйте zip, перенесите `app-debug.apk` на телефон и установите
   (разрешите установку из неизвестных источников).

## Настройка

Файл `capacitor.config.json`:
- `appName` — название приложения
- `appId` — уникальный id, например `com.mysite.game`

## Важно

- Это debug-APK: он устанавливается на телефон, но для Google Play нужен подписанный release-APK/AAB.
- Для иконки приложения можно позже подключить `@capacitor/assets`.
- Внешние ресурсы (CDN) требуют интернета; свои файлы работают офлайн.
